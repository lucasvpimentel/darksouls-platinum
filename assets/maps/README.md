# Imagens de mapa

Coloque aqui um arquivo por área, nomeado pelo id do atlas (ver `js/data/atlas.js`):
`firelink.jpg`, `burg.jpg`, `parish.jpg`, `depths.jpg`, `blight.jpg`, … (`.png` também funciona).

O modal tenta `assets/maps/<id>.jpg`, depois `.png`; se nenhum existir mostra a planta vetorial
com conexões e itens da rota. As imagens do guia da Steam são de terceiros: baixe e use apenas
se tiver autorização do autor — o app não faz hotlink para a CDN da Steam.
